# Hi, I'm Miretu Jaleta 👋

**Senior AI Software Engineer, Senior Full-Stack Developer & Computer Vision Engineer** at the Ethiopian Artificial Intelligence Institute, based in Addis Ababa, Ethiopia.

I build production AI applications end to end: computer vision systems, RAG and LLM apps, full-stack platforms, and BI dashboards. I am equally at home on the back end and the front end. I also design RL environments and coding evaluations for AI model training, including SWE-bench-style and Terminal-Bench tasks.

## What I work on

- **AI & Computer Vision:** detection and video-analysis pipelines, video data annotation, model deployment
- **LLM / RAG applications:** retrieval-augmented chatbots and AI APIs, agents and agent workflows (LangGraph, CrewAI), Groq API, MCP
- **Full-stack engineering:** Django REST, Java, Node.js and Express, microservices (Redis Pub/Sub), React (TypeScript), Tailwind CSS, Bootstrap, PostgreSQL, MongoDB, Docker, GitLab CI/CD
- **Evaluation engineering:** SWE-bench-style coding tasks, Terminal-Bench tasks, long-horizon RL tasks, deterministic verifiers and reward-hack-resistant tests (pytest, Vitest), benchmark design
